On-chip semi-device-independent quantum random number generator exploiting contextuality

저자: Maddalena Genzini, Caterina Vigliar, Mujtaba Zahidy, Hamid Tebyanian, Andrzej Gajda, Klaus Petermann, Lars Zimmermann, Davide Bacco, Francesco Da Ros | 날짜: 2026-01-13 | DOI: 10.48550/arxiv.2601.08392

Essence

실리콘 포토닉 칩 기반의 반신뢰 양자 난수 생성기를 구현하며, KCBS 맥락성 부등식 위반을 통해 양자적 난수를 인증하고 21.7 bits/s의 생성률을 달성했다.

Motivation

  • Known: 양자 난수 생성기는 완전신뢰(fully trusted), 완전장치독립(device-independent), 반신뢰(semi-device-independent) 방식이 존재하며, 반신뢰 방식은 Bell 부등식 대신 맥락성 테스트를 이용하여 실험 구현을 단순화할 수 있다.
  • Gap: 기존 집적 QRNG는 대부분 완전신뢰 가정 하에서만 작동하며, 손상되거나 불완전하게 특성화된 장치에서도 검증 가능한 난수를 생성하는 집적 반신뢰 QRNG의 실험적 구현이 부재했다.
  • Why: 맥락성 기반 반신뢰 QRNG는 얽힘이 불필요하면서도 장치 신뢰성 없이 난수를 인증할 수 있어, 실제 양자 네트워크(QKD, 분산 양자 컴퓨팅)에 임베드 가능한 범용 해결책을 제공한다.
  • Approach: 두 개의 실리콘 포토닉 칩을 통합하여 herald된 단일 광자 원과 재구성 가능한 MZI 메시 기반 qutrit 상태 준비/변환/측정을 구현하고, KCBS 부등식을 테스트하여 맥락성을 검증한다.

Achievement

  • 맥락성 위반 관찰: 10σ 이상으로 고전 한계를 초과하는 −3.84 ± 0.08의 KCBS 부등식 위반 달성
  • 난수 인증: semidefinite programming 기반 보안 분석을 통해 조건부 min-entropy Hmin = 0.077 ± 0.002 bits를 검증
  • 생성 속도: 0.077 ± 0.002 bits/라운드에서 비롯된 21.7 ± 0.5 bits/s의 점근 생성률 달성
  • 집적 구현: 전체 시스템의 물리적 설치 공간을 대폭 감소시킨 온칩 반신뢰 QRNG 구현

How

  • herald된 단일 광자 원(SFWM 기반)에서 qutrit을 준비하기 위한 양자 상태 생성
  • 72개 MZI로 구성된 육각형 격자 메시를 통해 qutrit의 회전과 변환 구현 (각 MZI는 0 < Δφ < 2π 범위의 재구성 가능한 광학 소자)
  • KCBS 부등식의 다섯 개 양립 가능한 dichotomic 측정(A₁~A₅)을 순환 호환성 구조로 구현
  • superconducting nanowire single-photon detector (SNSPD)와 time tagger를 통한 광자 계수 및 측정 결과 기록
  • semidefinite programming 기반 맞춤형 보안 분석을 통해 KCBS 위반으로부터 min-entropy 도출
  • 사후 처리(post-processing)에서 난수 추출 및 인증

Originality

  • 맥락성(contextuality) 기반 반신뢰 QRNG를 실리콘 포토닉 칩에 처음 온칩 구현
  • herald된 단일 광자와 재구성 가능한 MZI 메시를 조합하여 qutrit 제어의 정밀도와 안정성을 확보
  • KCBS 부등식 기반 맥락성 검증과 min-entropy 인증을 통합한 새로운 보안 분석 프레임워크 개발
  • 완전장치독립 방식(Bell 부등식)의 높은 요구 조건 없이 실질적 생성 속도(tens of bits/s)를 달성한 중간 입장의 선택

Limitation & Further Study

  • 생성 속도 21.7 bits/s는 완전신뢰 방식의 Gb/s 범위에 비해 여전히 낮음
  • min-entropy 값 0.077 bits/라운드는 상대적으로 낮아 고속 난수 추출을 위해 추가 분석이 필요
  • 현재 구현은 개념 증명(proof-of-concept) 수준이며, 장기 안정성 및 대규모 네트워크 통합의 타당성 검증 필요
  • KCBS 시나리오는 qutrit (3차원)만 다루므로, 더 높은 차원 또는 다중 파티 맥락성 테스트로의 확장 가능성 탐색 필요
  • 실제 QKD/분산 양자 컴퓨팅 시스템과의 실시간 통합 실험 미실시

Evaluation

Novelty: 4/5 Technical Soundness: 4/5 Significance: 4/5 Clarity: 4/5 Overall: 4/5

총평: 본 논문은 맥락성 기반 반신뢰 QRNG를 실리콘 포토닉 칩에 처음 성공적으로 구현하여, 완전장치독립 방식의 높은 요구 조건을 완화하면서도 난수의 양자적 본질을 검증 가능하게 하였다. 통합 광자 네트워크에 호환 가능한 범용 반신뢰 QRNG로의 명확한 길을 제시하는 중요한 기여이다.
