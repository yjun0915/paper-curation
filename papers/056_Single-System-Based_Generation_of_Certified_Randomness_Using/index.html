Single-System-Based Generation of Certified Randomness Using Leggett-Garg Inequality

저자: Pingal Pratyush Nath, Debashis Saha, Dipankar Home, Urbasi Sinha | 날짜: 2024-07-10 | DOI: 10.1103/physrevlett.133.020802

Essence

Leggett-Garg inequality 위반을 이용한 단일 광자 기반의 반-기기-독립적 양자 난수 생성 방식을 이론적으로 제안하고 실험적으로 입증했으며, 초당 3865비트의 속도로 919,118개의 진정한 난수 비트를 안전하게 생성했다.

Motivation

  • Known: Bell inequality 위반을 이용한 완전 기기-독립적 난수 생성이 알려져 있으나, 두 당사자 간의 공간적 분리 요구로 실험적으로 구현하기 어렵다. Leggett-Garg inequality는 시간적 비고전성을 테스트하는 데 주로 사용되어 왔다.
  • Gap: 기존 방식의 공간적 분리 요구를 극복하고 단일 시스템의 양자성만으로 인증된 난수를 생성할 수 있는 실용적 방법이 부재했다.
  • Why: 암호화 및 보안 통신 프로토콜에서 진정한 난수의 신뢰성이 필수적이며, 기기 불완전성과 공격자 개입에도 견딜 수 있는 안전한 난수 생성기가 필요하다.
  • Approach: LGI가 Predictability와 No-Signaling-in-Time(NSIT) 가정으로부터도 도출될 수 있다는 점을 활용하여, LGI 위반과 NSIT 만족 조건 하에서 측정 결과의 내재적 불예측성을 보장한다. 최소 엔트로피(minimum entropy)로 생성된 난수를 정량화한다.

Achievement

  • 반-기기-독립적 난수 생성: Leggett-Garg inequality 위반으로부터 인증된 난수를 생성하는 새로운 방식을 제시했다.
  • loophole-free 실험: 광자 기반 아키텍처에서 모든 관련 허점을 메우고 NSIT 조건을 엄격히 만족시켰다.
  • 이론과 실험의 완벽한 일치: 분석적 및 수치적 접근법이 일치하여 randomness 정량화의 엄밀성을 입증했다.
  • 고속 난수 생성: 초당 3865비트의 속도로 919,118개의 확인된 난수 비트를 생성했다.
  • 단일 시스템 기반: 얽힘이 필요 없는 단일 시스템만으로 양자성을 활용한 난수 생성을 최초 입증했다.

How

  • 세 시점 t₁, t₂, t₃에서 이분 변수 Q에 대한 측정을 수행하고 Leggett-Garg inequality ⟨Q₁Q₂⟩ + ⟨Q₂Q₃⟩ - ⟨Q₁Q₃⟩ ≤ 1을 위반하는지 확인
  • t₁, t₂에서는 차단기(blocker)를 이용한 사영 측정(projective measurement)을 수행
  • t₃에서는 일반적 POVM 측정을 수행하되, 차단기가 뒤의 측정에 신호를 보내지 않음을 보장
  • 세 가지 No-Signaling-in-Time 조건 P(+|Qⱼ) = Σₐᵢ P(aᵢ+|Qᵢ, Qⱼ)을 만족하는지 검증
  • 최소 엔트로피 H∞ = -log₂(maxₐᵢ,ₐⱼ P(aᵢ, aⱼ|Qᵢ, Qⱼ))를 계산하여 randomness 정량화
  • 최적화 문제를 풀어 LGI 위반 정도 α에 따른 보장된 randomness의 하한을 도출
  • Theorem 1을 통해 P = ¼(1 + α + √(1-2α))를 증명하고 보장된 난수 비트 -log₂(P)를 계산

Originality

  • LGI의 시간적 비고전성을 난수 생성에 최초 적용한 응용 지향적 연구
  • 단일 시스템만으로 반-기기-독립적 난수를 생성하는 새로운 패러다임 제시
  • LGI를 Predictability와 NSIT로부터 유도하여 난수의 unpredictability를 엄밀히 보장
  • 최소 엔트로피와 LGI 위반의 명시적 관계식(Theorem 1) 도출
  • 초기 상태 준비에 대한 공격(adversarial state preparation)으로부터의 보안 분석 포함

Limitation & Further Study

  • 반-기기-독립적 방식이므로 가정된 조건들(2차원성, 측정 형태, 상태 독립성)의 만족 정도에 따라 보장 정도가 결정됨
  • 초당 3865비트의 생성 속도는 기존 고전 RNG에 비해 낮아 실용성 개선 필요
  • 특정 광자 기반 실험 장치에 의존하므로 다른 양자 시스템으로의 확장성 검증 필요
  • NSIT 조건 검증이 실험적 통계 오차의 영향을 받을 수 있으므로 더 큰 샘플 크기에서의 재검증 요망
  • Eve의 얽힌 초기 상태 공격 시나리오에 대한 보안 분석이 아직 불완전하다고 언급함

Evaluation

Novelty: 4/5 Technical Soundness: 3/5 Significance: 4/5 Clarity: 4/5 Overall: 4/5

총평: 양자 난수 생성의 새로운 패러다임을 제시하며, loophole-free 실험과 엄밀한 이론적 증명으로 신뢰성을 확보했다. 단일 시스템 기반의 반-기기-독립적 접근으로 실용성을 크게 향상시켰으나, 생성 속도 개선과 더 넓은 시스템으로의 확장이 향후 과제이다.
