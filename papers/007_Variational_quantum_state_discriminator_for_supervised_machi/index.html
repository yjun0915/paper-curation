Variational quantum state discriminator for supervised machine learning

저자: Dongkeun Lee, Kyunghyun Baek, Joonsuk Huh, Daniel K Park | 날짜: 2024-01-01 | DOI: 10.1088/2058-9565/ad0a05

Essence

양자 상태 판별(QSD)을 위한 변분 양자 알고리즘(VQSD)을 제시하며, 이를 지도 학습 기반 다중 분류 문제에 적용한다.

Motivation

  • Known: 양자 상태 판별은 양자 정보 처리의 기본 작업이며, 최적 POVM을 찾기 위해 고전적으로는 semidefinite programming(SDP)이 사용되어 왔다.
  • Gap: 고전적 최적화 방법은 양자 상태 전층 측정(quantum state tomography)이 필요하고 큐빗 수에 지수적으로 복잡도가 증가하며, 찾은 POVM을 양자 회로로 변환하기 어렵다.
  • Why: 양자 컴퓨터에서 직접 최적 POVM을 찾을 수 있다면 계산 복잡도를 줄이고 미지의 상태도 판별 가능하며, 양자 기계 학습의 새로운 접근법을 제공할 수 있다.
  • Approach: 매개변수화된 양자 회로를 QSD로부터 유도된 비용 함수로 훈련하여 최적 POVM을 찾는 변분 양자 알고리즘을 제시하고, 이를 다중 분류 문제에 확장한다.

Achievement

Figure 4. Minimum-error QSD using the variational quantum algorithm. Sets of a priori quantum states are given as (a)

  • 최적 POVM 찾기: VQSD는 순수 상태와 혼합 상태 모두에 대해 최소 오류 QSD를 위한 최적 POVM을 찾으며, SDP와의 비교를 통해 효과성을 입증했다.
  • 미지의 상태 판별: 양자 상태 전층 측정 없이도 미지의 상태를 판별할 수 있어 비용이 많이 드는 측정 과정을 제거했다.
  • 기계 학습 응용: VQSD를 지도 학습 기반 다중 분류 알고리즘으로 활용하여 Iris flower 데이터셋에서 평균 0.985의 우수한 AUC 성능을 달성했다.
  • 일반적 해법: 임의의 차원을 가진 양자 시스템(순수/혼합 상태)에 대해 체계적으로 작동하는 일반적인 알고리즘을 제시했다.

How

Figure 1. The circuit diagram for the unitary operation U. It describes performing POVMs on the arbitrary quantum states

  • Neumark 정리를 이용하여 임의의 POVM을 대상 양자 상태와 보조 큐빗으로 구성된 확장 시스템에 unitary 연산을 적용하여 구현
  • Cosine-Sine Decomposition(CSD)을 기반으로 POVM 회로를 uniformly controlled gates와 single-qubit rotation으로 분해
  • 매개변수화된 양자 회로 U(Θ)를 통해 POVM 원소 E_m(Θ)를 생성하고 보조 큐빗 측정으로 결과 m 획득
  • QSD 이론에서 유도된 비용 함수를 최소화하여 최적 매개변수 Θ를 학습하는 변분 훈련 절차
  • 양자 특성 맵(quantum feature map)을 사용하여 고전 데이터를 양자 상태로 인코딩한 후 VQSD로 분류

Originality

  • 기존 두 큐빗 4-원소 POVM의 gate 분해를 일반화하여 임의의 큐빗 수와 POVM 원소 개수에 적용 가능하게 함
  • 양자 상태 전층 측정 없이 직접 변분 알고리즘으로 최적 POVM을 찾는 새로운 접근법
  • QSD 이론을 지도 학습 기반 다중 분류 문제로 확장하여 양자 기계 학습의 새로운 응용 제시
  • POVM 회로의 체계적인 분해 방법론과 실제 양자 회로 구현 가능한 형태로의 변환

Limitation & Further Study

  • 현재 수치 모의실험(numerical simulation) 결과만 제시되었으며 실제 양자 장치에서의 구현 및 성능 검증이 필요
  • 보조 큐빗 수와 POVM 원소 수가 증가함에 따른 회로 깊이 증가로 인한 실제 NISQ 장치의 노이즈 영향에 대한 분석 부족
  • 고전 기계 학습 알고리즘과의 상세한 성능 비교가 제한적임
  • 후속 연구: 실제 양자 장치(IBMQ, IonQ 등)에서의 구현 및 오류 완화(error mitigation) 기법 적용, 더 복잡한 데이터셋에 대한 확장성 검증, 양자 장점(quantum advantage) 달성 조건 분석

Evaluation

Novelty: 4/5 Technical Soundness: 3/5 Significance: 4/5 Clarity: 4/5 Overall: 4/5

총평: 본 논문은 양자 상태 판별을 위한 실용적인 변분 양자 알고리즘을 제시하고 이를 기계 학습에 응용한 창의적인 연구로, 양자 컴퓨팅과 기계 학습의 결합 분야에 유의미한 기여를 한다. 다만 실제 양자 장치 구현이 필요하다.
